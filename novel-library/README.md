# คลังนิยายออนไลน์

ระบบจัดเก็บและอ่านนิยาย เขียนด้วย PHP 8.2 ขึ้นไป, HTML5, Bootstrap 5, SweetAlert2 และ Font Awesome ใช้ MySQL หรือ MariaDB และจัดการฐานข้อมูลผ่าน phpMyAdmin

โครงหน้าแยกเป็นห้าส่วนที่ใช้ร่วมกันทุกหน้า:

1. `includes/header.php` เปิดเอกสาร HTML5 โหลดฟอนต์ บูตสแตรป ไอคอน และซีเอสเอส
2. `includes/navbar.php` แถบค้นหา เมนู และบัญชีผู้ใช้
3. `includes/sidebar.php` หมวดหมู่ ทางลัด และเมนูผู้ดูแล บนเดสก์ท็อปเป็นคอลัมน์ซ้าย บนมือถือและแท็บเล็ตเป็นแผงสไลด์
4. `content/` เนื้อหาของแต่ละหน้า
5. `includes/footer.php` ท้ายหน้าและสคริปต์ รวมถึง SweetAlert2

## 1. สิ่งที่ต้องมี

- PHP 8.2.0 หรือใหม่กว่า พร้อมส่วนขยาย `pdo_mysql`, `mysqli`, `mbstring`, `fileinfo`
- MySQL 8 หรือ MariaDB 10.4 ขึ้นไป
- phpMyAdmin สำหรับสร้างฐานข้อมูลและนำเข้าไฟล์ SQL
- เว็บเซิร์ฟเวอร์ที่ชี้ document root มาที่โฟลเดอร์ `novel-library` เช่น Apache หรือ Nginx
- ทดลองบนเครื่องตัวเองได้ด้วยเซิร์ฟเวอร์ในตัวของ PHP โดยไม่ต้องลง Apache

ตรวจรุ่น PHP:

```bash
php -v
```

ถ้าได้ 8.2 หรือ 8.3 ขึ้นไป ใช้ได้ทันที

## 2. โครงสร้างไฟล์

```text
novel-library/
├── index.php              จุดเข้าเดียว เลือกหน้าจากพารามิเตอร์ page
├── install.php            ตัวช่วยนำเข้า schema หลังจากเชื่อมฐานข้อมูลได้
├── router.php             เราเตอร์สำหรับ php -S
├── config/config.php      ค่าเชื่อมต่อฐานข้อมูลและชื่อระบบ
├── includes/
│   ├── bootstrap.php      เปิดเซสชันและโหลดฟังก์ชัน
│   ├── header.php
│   ├── navbar.php
│   ├── sidebar.php
│   ├── footer.php
│   ├── functions.php      ส่วนกลาง ความปลอดภัย และรูปแบบหน้า
│   ├── library.php        คิวรีนิยาย ตอน หมวด และผู้ใช้
│   └── post/              รับฟอร์มแล้วเปลี่ยนเส้นทางกลับ
├── content/               หน้าฝั่งผู้อ่าน
│   └── admin/             หน้าฝั่งผู้ดูแล
├── assets/css/style.css
├── assets/js/app.js
├── sql/create_database.sql
├── sql/schema.sql
└── uploads/covers/        ปกที่ผู้ดูแลอัปโหลด
```

การเปิดหน้าหนึ่งหน้าเกิดตามลำดับนี้:

1. เบราว์เซอร์ขอ `index.php?page=novel&slug=moonlight-roof`
2. `bootstrap.php` ตรวจว่า PHP ตั้งแต่ 8.2 แล้วเปิดเซสชัน
3. รายการใน `includes/routes.php` ตรวจว่าชื่อหน้าได้รับอนุญาต
4. ถ้าต้องเข้าสู่ระบบหรือเป็นผู้ดูแล ระบบตรวจสิทธิ์ก่อนพิมพ์ HTML
5. ถ้าเป็นฟอร์ม จะตรวจโทเคน CSRF แล้วค่อยบันทึก
6. จากนั้นจึงประกอบ header, navbar, sidebar, content และ footer

## 3. สร้างฐานข้อมูลด้วย phpMyAdmin

### ขั้นที่ 1 สร้างฐานข้อมูล

1. เปิด phpMyAdmin แล้วเข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์สร้างฐานข้อมูล
2. ไปที่แท็บ **Databases** หรือ **ฐานข้อมูล**
3. ตั้งชื่อ `novel_library`
4. เลือก collation เป็น `utf8mb4_unicode_ci`
5. กดสร้าง

ถ้าต้องการให้สคริปต์สร้างฐานข้อมูลและผู้ใช้ให้ ใช้นัญชี root รันไฟล์ `sql/create_database.sql` แล้วเปลี่ยนรหัสผ่านทันที

### ขั้นที่ 2 สร้างผู้ใช้สำหรับเว็บ

1. เปิดแท็บ **User accounts** หรือ **บัญชีผู้ใช้**
2. เพิ่มผู้ใช้ `novel_user` โฮสต์ `localhost`
3. ตั้งรหัสผ่าน แล้วให้สิทธิ์ทั้งหมดเฉพาะฐานข้อมูล `novel_library`
4. อย่าให้สิทธิ์ระดับทั้งเซิร์ฟเวอร์

### ขั้นที่ 3 นำเข้าตารางและข้อมูลตัวอย่าง

1. คลิกชื่อฐานข้อมูล `novel_library` ในแถบซ้าย จน phpMyAdmin บอกว่ากำลังใช้งานฐานนี้
2. เปิดแท็บ **Import**
3. เลือกไฟล์ `novel-library/sql/schema.sql`
4. ชุดอักขระของไฟล์เลือก `utf-8`
5. กด **Go** หรือ **ดำเนินการ**

เมื่อสำเร็จจะมีตาราง `users`, `categories`, `novels`, `chapters`, `bookmarks` และ `reading_progress` พร้อมนิยายตัวอย่าง 6 เรื่องที่เปิดอ่านได้ และอีก 1 เรื่องที่ยังเป็นฉบับร่าง

ไฟล์นี้นำเข้าซ้ำได้ แต่จะลบข้อมูลเดิมของตารางชุดนี้ก่อนสร้างใหม่ ควรส่งออกสำรองจากแท็บ Export ก่อนทุกครั้ง

## 4. ตั้งค่าการเชื่อมต่อ

เปิด `config/config.php` แล้วให้ค่า `db` ตรงกับ phpMyAdmin:

- `host` มักเป็น `127.0.0.1`
- `port` มักเป็น `3306`
- `name` คือ `novel_library`
- `user` และ `pass` คือผู้ใช้ที่สร้างไว้

บนเซิร์ฟเวอร์จริงควรตั้งรหัสผ่านผ่านตัวแปรสภาพแวดล้อมแทนการแก้ไฟล์:

- `NOVEL_DB_HOST`
- `NOVEL_DB_PORT`
- `NOVEL_DB_NAME`
- `NOVEL_DB_USER`
- `NOVEL_DB_PASS`

ก่อนเปิดสู่สาธารณะ ให้ตั้ง `show_demo_accounts` เป็น `false` เพื่อไม่แสดงบัญชีทดลองบนหน้าเข้าสู่ระบบ และตั้ง `debug` เป็น `false`

## 5. สิทธิ์โฟลเดอร์

เว็บเซิร์ฟเวอร์ต้องเขียนไฟล์ได้ที่:

- `uploads/covers` สำหรับปก
- `storage/sessions` สำหรับเซสชัน
- `storage` สำหรับบันทึกข้อผิดพลาด

ตัวอย่างบนลินุกซ์:

```bash
chmod 775 novel-library/uploads/covers novel-library/storage novel-library/storage/sessions
```

## 6. เปิดเว็บ

ชี้ document root ไปที่โฟลเดอร์ `novel-library` ไม่ใช่โฟลเดอร์แม่ของโปรเจกต์ แล้วเปิด `index.php`

ทดลองด้วยเซิร์ฟเวอร์ในตัวของ PHP จากโฟลเดอร์แม่ของโปรเจกต์:

```bash
php -S 127.0.0.1:8080 -t novel-library novel-library/router.php
```

จากนั้นเปิด `http://127.0.0.1:8080`

ถ้าเชื่อมต่อฐานข้อมูลได้แล้ว แต่ยังไม่ได้มีตาราง ให้เปิด `install.php` แล้วยืนยันการนำเข้า `schema.sql` อีกทางหนึ่งจากหน้าเว็บ หลังนำเข้าสำเร็จจะมีไฟล์ `install.lock` เพื่อไม่ให้รันซ้ำโดยไม่ตั้งใจ

## 7. บัญชีเริ่มต้น

รหัสเหล่านี้มาพร้อมข้อมูลตัวอย่าง เปลี่ยนหรือปิดการแสดงทันทีเมื่อใช้งานจริง

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
| --- | --- | --- |
| ผู้ดูแล | admin | Admin@1234 |
| นักอ่าน | reader | Reader@1234 |

## 8. วิธีใช้ฝั่งผู้อ่าน

1. เปิดหน้าแรกเพื่อดูเรื่องอัปเดตล่าสุด เรื่องที่มีคนเปิดบ่อย และหมวดหมู่
2. ใช้ช่องค้นหาเพื่อหาชื่อเรื่อง ผู้แต่ง เรื่องย่อ หรือหมวด
3. เปิดหน้านิยายเพื่ออ่านเรื่องย่อและสารบัญ
4. กดเริ่มอ่าน ตัวอักษรปรับขนาดได้ และสลับโหมดกลางวันกับกลางคืนได้
5. บนมือถือและแท็บเล็ตกดสารบัญเพื่อเปิดรายการตอน บนจอกว้างรายการตอนอยู่ด้านขวา
6. ปุ่มลูกศรซ้ายและขวาบนคีย์บอร์ดใช้เปลี่ยนตอนเมื่อไม่ได้กำลังพิมพ์ในช่องข้อความ
7. สมัครสมาชิกเพื่อเก็บเรื่องเข้าชั้นหนังสือ ระบบจะจำตอนล่าสุดของแต่ละเรื่องไว้ในหน้าอ่านค้างไว้

## 9. วิธีใช้ฝั่งผู้ดูแล

เข้าสู่ระบบด้วยบัญชีผู้ดูแล แล้วเปิด **จัดการระบบ**

1. แดชบอร์ดแสดงจำนวนเรื่อง ตอน ผู้ใช้ และยอดเปิดอ่าน
2. เพิ่มนิยายจากชื่อเรื่อง ผู้แต่ง หมวด เรื่องย่อ สถานะ และปก
3. ติ๊กเผยแพร่เมื่อต้องการให้ผู้อ่านเห็น ถ้าไม่ติ๊ก เรื่องจะเหลือเฉพาะในหน้าจัดการ และผู้ดูแลยังเปิดพรีวิวได้
4. ในหน้ารายการตอน เพิ่มหรือแก้เนื้อหาได้ เว้นบรรทัดว่างหนึ่งบรรทัดเพื่อขึ้นย่อหน้าใหม่
5. การลบเรื่อง ตอน หมวด หรือผู้ใช้ จะมีหน้าต่าง SweetAlert2 ให้ยืนยันก่อน
6. หมวดที่ยังมีนิยายอยู่จะลบไม่ได้ ต้องย้ายหรือลบเรื่องก่อน
7. ผู้ดูแลลบบัญชีของตนเองไม่ได้ และระบบไม่ให้เหลือผู้ดูแลเป็นศูนย์

## 10. มือถือ แท็บเล็ต และเดสก์ท็อป

ใช้ Bootstrap 5 เป็นตารางกริด และมีจุดเปลี่ยนที่ความกว้าง 576, 768, 992 และ 1200 พิกเซล

- มือถือ: การ์ดเรื่องละใบ แถบค้นหาเต็มความกว้าง หมวดหมู่อยู่ในแผงที่เปิดจากปุ่มมุมซ้าย เมนูบัญชีอยู่หลังปุ่มจุดสามจุด
- แท็บเล็ต: การ์ดสองคอลัมน์ แผงหมวดหมู่ยังเป็นแผงสไลด์ เพื่อไม่แย่งพื้นที่อ่าน
- เดสก์ท็อปตั้งแต่ 992 พิกเซล: ไซด์บาร์ติดซ้ายตลอด เนื้อหาอยู่คอลัมน์ขวา
- จอใหญ่ตั้งแต่ 1200 พิกเซล: หน้าอ่านมีสารบัญตอนอยู่ข้างบทความ

โหมดมืดจำไว้ในเบราว์เซอร์ของเครื่องนั้น ขนาดตัวอักษรตอนอ่านก็จำไว้เช่นกัน

## 11. ความปลอดภัยที่ใช้ในโค้ด

- รหัสผ่านเก็บด้วย `password_hash` และตรวจด้วย `password_verify`
- คิวรีใช้ prepared statement
- ข้อความที่มาจากฐานข้อมูลถูกescape ก่อนแสดง
- ฟอร์มมีโทเคน CSRF
- อัปโหลดปกตรวจชนิดไฟล์จริง อนุญาตเฉพาะ JPG, PNG และ WEBP ขนาดไม่เกิน 2 MB
- หน้าจัดการตรวจบทบาท `admin` ก่อนเปิดและก่อนบันทึก
- โฟลเดอร์ `config`, `includes`, `storage` และ `sql` ถูกกันไม่ให้เปิดตรงจากเว็บ

## 12. แก้ปัญหาเบื้องต้น

- หน้าแรกขึ้นว่ายังเชื่อมฐานข้อมูลไม่ได้: ตรวจชื่อฐานข้อมูล ผู้ใช้ รหัสผ่าน และว่าได้นำเข้า `schema.sql` ขณะที่เลือกฐานข้อมูลนั้นอยู่
- ภาษาไทยเป็นเครื่องหมายคำถาม: ชุดอักขระของฐานข้อมูลต้องเป็น `utf8mb4` และไฟล์ PHP บันทึกเป็น UTF-8
- เข้าสู่ระบบไม่ได้ทั้งที่กรอกรหัสถูก: ตรวจว่าโฟลเดอร์ `storage/sessions` เขียนได้
- อัปโหลดปกไม่ได้: ตรวจสิทธิ์ `uploads/covers` และค่า `upload_max_filesize` ใน PHP ให้มากกว่า 2M
- SweetAlert2 ไม่ขึ้น แต่ยังเห็นแถบแจ้งเตือน: สคริปต์จาก CDN โหลดไม่สำเร็จ แถบแจ้งเตือนเป็นทางสำรองเมื่อจาวาสคริปต์ไม่ทำงาน
